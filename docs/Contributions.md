# Contributions

This project relies on the following open-source libraries and tools:

- **SFML** (Simple and Fast Multimedia Library) – for windowing, graphics, audio, networking, etc.
- **glm** – OpenGL Mathematics library for vector and matrix math.
- **Tracy** – real-time, nanosecond-resolution remote profiler.
- **nlohmann JSON** – JSON for Modern C++ (used for parsing Tiled map files).
- **tinyxml2** – tiny XML parser (used for parsing Tiled tileset files).

Additionally, the following tools are used:

- **Tiled** – a flexible level editor used to create tilemaps, tilesets, and map projects.

If you have contributed code, documentation, assets, or any other improvements, please feel free to add your name here!
